# 🛒 E-Commerce Web Application

A complete beginner-friendly full-stack e-commerce project built for a college assignment.

## 🌐 Live Demo

**Live Website:**  
https://ecommerce-web-app-alpha-gold.vercel.app/

**GitHub Repository:**  
https://github.com/ARKANMANSOORI/ecommerce-web-app

---

## ✨ Features

- Product catalog
- Product details
- User registration and login
- JWT authentication
- User/Admin role-based access
- Shopping cart
- Checkout
- Order history
- Admin product CRUD
- Admin order management
- MongoDB integration
- Express REST APIs
- React frontend
- Responsive UI

---

## 🛠️ Tech Stack

### Frontend

- React
- Vite
- React Router
- Plain CSS

### Backend

- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- bcryptjs
- CORS
- dotenv

---

## 📋 Requirements

Install these first:

- Node.js 18+
- MongoDB Community Server OR MongoDB Atlas
- VS Code (recommended)
